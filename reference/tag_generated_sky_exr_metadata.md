# Tag generated sky EXR metadata

Tag generated sky EXR metadata

## Usage

``` r
tag_generated_sky_exr_metadata(sky, hosek, exr_metadata, exr_adopted_white)
```

## Arguments

- sky:

  Sky image array.

- hosek:

  Whether the Hosek-Wilkie model was used.

- exr_metadata:

  Whether to attach skymodelr EXR metadata.

- exr_adopted_white:

  Adopted white name or XYZ vector.
